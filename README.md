# SAE-AUTO-SCRIPT

Python tabanlı Roblox yardımcı aracı.

## Özellikler
- Yerel, hassas olmayan kullanıcı metadata yönetimi
- Güvenli JSON saklama
- Loglama ve hata yönetimi
- Roblox public Games API üzerinden oyun bilgisi sorgulama
- Girdi doğrulama ve atomic JSON yazımı

## Kurulum

```bash
python -m pip install -r requirements.txt
python roblox_mega_bot.py
```

## Not
Bu sürüm sahte hesap üretmez, şifre/cookie toplamaz, ücretsiz proxy/VPN listesi kullanmaz, IP rotasyonu yapmaz ve çoklu hesapla otomatik oyuna giriş gerçekleştirmez.
